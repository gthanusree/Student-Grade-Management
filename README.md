# Grade Tracking Student System

A Java console application for managing student records, marks, CGPA and ranking.

## Features
- Add students by roll number and name
- Add or update marks per subject (0-100)
- View a report card with grade points and CGPA
- View a rank list sorted by CGPA

## How to run
1. Open the `TeamProject` folder in VS Code.
2. Open `src/Main.java` and click Run.
